GUESS THE NUMBER 

Моя учебная игра на Python

Цель проекта:

Сначало реализовать игру простым способом - с использованием циклов и условных конструкций.

Затем самостоятельно переработать игру с использованием функций и сравнить два подхода:

простой вариант и разделеный на функции.

Главная цель - не просто написать игру, а понять работу функций, циклов, ну и return, и как они помогают сделать код понятным и удобным.

Version 1

Первая игра написана простым способом: 

1. While
2. For
3. IF/elif/else
4. input()
5. Переменные
6. Random

Цель: понять работу циклов и условий.
